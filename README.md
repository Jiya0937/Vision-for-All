# BrailleAI – Vision For All

BrailleAI is an AI-powered Braille detection and translation system developed during hackathon using YOLOv8 and OpenCV.

## Features

- Braille image upload
- YOLOv8 custom trained model
- Braille character detection
- Flask AI API
- Node.js backend
- Premium frontend UI
- Live webcam preview

## Tech Stack

- YOLOv8
- OpenCV
- Flask
- Node.js
- HTML/CSS/JavaScript

## Model

Custom trained YOLOv8 model:
- best.pt

## Run Project

### Install Python Packages

pip install -r requirements.txt

### Start Flask API

python flask_api.py

### Start Node Backend

cd backend
node server.js

### Open Website

http://localhost:5000
